# The technologies used in this project

### Docker
Abstract the dependencies on your operating system and installed script. You only need docker and nothing else to start.

### Bun
The runtime for the TypeScript code as a modern alternative to NodeJS.

### ESLint
Linter for checking formatting and keeping best-practices. Also used to prohibit
imports across client and server code.

### Husky

### ReactJS
Frontend framework using component-based virtual DOM and JSX layout.
